# Glossary

*Recap written with AI assistance from the files listed below. It describes what the record contains; it is not part of the record and does not verify it. Read the source files before quoting.*

**Covers:** 18 term files in `glossary/` and 58 term files plus a README in `glossary-site/` · about 14,000 words.

## What it covers

The glossary defines the vocabulary that the journal, concepts and reference documents use. It comes in two sets, which the site shows together:

- **`glossary/` (18 terms, about 1,500 words):** terms taken from the original source series, Part 01. Each file carries a `source_doc_id` back to that document. Most are dictionary-style entries with a pronunciation, part of speech, definitions and an example sentence. Examples are artificial intelligence, brain–computer interface, cognitive liberty, chilling effect, electroencephalograph, perceptual set, telepathy, terrorism and torment (for example IS-GLO-ARTIFICIAL-INTELLIGENCE).
- **`glossary-site/` (58 terms, about 12,600 words):** terms written for the website to explain the work. These carry `provenance: site-authored` and no source-document id (`glossary-site/README.md`). They are longer, and most end with a "Related terms" line and a "Sources" line that links to public references (for example IS-GLO-SITE-TINNITUS).

## How to use it

- Look a term up by file name: `IS_GLO_<term>.md` for source-series terms, `IS_GLO_SITE_<term>.md` for site-authored ones. The slug matches the site URL `/glossary/<slug>`.
- Check provenance before quoting. A `glossary/` entry records how the source series used a word. A `glossary-site/` entry is explanatory text written later, with its own cited sources.
- A definition explains a word. It does not establish that the thing the word describes happened in this record. Several site terms describe documented technologies, and the terms file states that placing a documented device beside an undocumented experience does not corroborate either (`meta/IS_META_terms.md`).

## Before asking questions of it

The source-series set keeps some spellings and duplicates from the original: a file named `euthanisia`, separate `telepathic` and `telepathy` entries, and both `electroencephalogram` and `electroencephalograph-eeg`. One source-series entry quotes a vendor's product description as its definition. The working note `research/notes/glossary-cleanup.md` records a later correction pass on the site's copy, which is not fully reflected in these files.
