# Discovery Notes — unofficial entries

**These are unofficial entries: the author's discovery notes, not journal entries.**

The author keeps working notes, and journal entries are written from notes like
these. The files in this folder are those notes, one file per note, in the
journal's format so they can be read beside it. Do not quote or cite them as
official journal entries.

- **22 notes** published so far, from 9 April – 24 May 2026. The official
  journal's last dated entry is 6 April 2026. Further notes from the same period
  are held for the author's review.
- Each file opens with a heading and a brief summary written by the editor from
  the note, marked as such. Below them the note keeps the author's words exactly,
  typos included. A line that is only a time, and the Questions & Comments label,
  are set as headings, as in the journal.
- Statements quoted in these notes are external communications, not the author's
  views or accusations. Read the Critical Disclaimer (below, and in
  `meta/IS_META_terms.md`) before quoting anything.
- Where a note corrects its own date, the file's front matter says so
  (`date_note`).

Official entries are in `journal/part-01/` to `journal/part-04/`.

File names: `IS_JDN_<date>_<time>_notes.md`. IDs: `IS-JDN-<date>-<time>`.
